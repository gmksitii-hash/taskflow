# ADR-001: Модульний моноліт як початкова архітектура
- **Статус:** Прийнято
- **Контекст:** команда з 5 осіб без досвіду експлуатації розподілених систем; потрібно швидко постачати функції; навантаження помірне (до 300 запитів/с).
- **Рішення:** серверна частина — один застосунок FastAPI, поділений на модулі `teams`, `boards`, `tasks`, `notifications` з явними інтерфейсами; спільна БД PostgreSQL.
- **Наслідки:** (+) просте розгортання й тестування, швидкий старт; (−) масштабування лише всього застосунку.
